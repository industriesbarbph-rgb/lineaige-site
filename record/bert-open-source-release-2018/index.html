BERT Open-Source Release

Google AI announced the open-source release of BERT on November 2, 2018. The release included TensorFlow source code and pre-trained language representation models. The associated authors' paper describes BERT as Bidirectional Encoder Representations from Transformers and as a method for pre-training deep bidirectional representations from unlabeled text.
