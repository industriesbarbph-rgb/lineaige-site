You Only Look Once: Unified, Real-Time Object Detection

Joseph Redmon, Santosh Divvala, Ross Girshick and Ali Farhadi submitted You Only Look Once: Unified, Real-Time Object Detection to arXiv on June 8, 2015. The paper presents YOLO as an object-detection approach that frames detection as a regression problem and uses a single neural network to predict bounding boxes and class probabilities directly from full images in one evaluation.
