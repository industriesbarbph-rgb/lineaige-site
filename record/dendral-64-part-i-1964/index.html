DENDRAL-64 — Part I: Notational Algorithm for Tree Structures

Joshua Lederberg's DENDRAL-64 technical report, Part I, was published on December 15, 1964. The report documents a system for computer construction, enumeration and notation of organic molecules as tree structures and cyclic graphs, with Part I devoted to a notational algorithm for tree structures.
