Upgraded Claude 3.5 Sonnet and Computer Use Public Beta

Anthropic announced an upgraded Claude 3.5 Sonnet on October 22, 2024 and introduced computer use in public beta. Anthropic stated that the upgraded Claude 3.5 Sonnet was available to all users and that developers could build with the computer use beta through the Anthropic API, Amazon Bedrock, and Google Cloud Vertex AI starting that day.
