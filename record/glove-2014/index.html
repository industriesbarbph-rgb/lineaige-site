GloVe original release

The Stanford NLP Group records August 2014 as the original release of GloVe, prepared by Jeffrey Pennington. The project describes GloVe as an unsupervised learning algorithm for obtaining vector representations for words from aggregated global word-word co-occurrence statistics.
