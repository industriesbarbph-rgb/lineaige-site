CNTK GitHub Repository Goes Public

Microsoft's CNTK project history records that the CNTK repository on GitHub went public on January 25, 2016, together with a new CNTK website.

Microsoft's official CNTK project history explicitly records '2016-01-25 13:00 GMT. CNTK new repository in GitHub went public' and notes that the CNTK website became available at the same time. Microsoft's dated January 25, 2016 AI Blog announcement independently states that the company was releasing CNTK on GitHub, and a Microsoft Research post published June 10, 2016 states that earlier in 2016 Microsoft made its open-source Computational Network Toolkit available on GitHub. This candidate is limited to the GitHub-public milestone and does not infer an invention/system-birth date, development geography, universal priority, ancestry, influence, causality, or unsupported relationship.
