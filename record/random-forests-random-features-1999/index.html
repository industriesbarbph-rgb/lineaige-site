Random Forests--Random Features

Leo Breiman's University of California, Berkeley Statistics technical report 'Random Forests--Random Features' is dated September 1, 1999. The report describes random forests as combinations of tree predictors in which each tree depends on an independently sampled random vector, and discusses random feature selection for tree splitting.
