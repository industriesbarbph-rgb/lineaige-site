Google's first-party announcement dated November 9, 2015 introduces TensorFlow and explicitly says Google was open-sourcing TensorFlow that day. The TensorFlow authors' technical paper independently states that the TensorFlow API and reference implementation were released as an open-source package under the Apache 2.0 license in November 2015. Google Research's institutional publication record independently preserves that same paper and its November 2015 open-source-release statement. This candidate records the November 9 public open-source release milestone only; it does not infer TensorFlow's invention date, development geography, universal priority, ancestry, influence, causality, or relationship edges.
