Long Short-Term Memory

Sepp Hochreiter and Jürgen Schmidhuber published Long Short-Term Memory in Neural Computation on 15 November 1997. The paper introduced the gradient-based method called long short-term memory (LSTM), using constant error flow and multiplicative gate units to address long time-lag learning problems in recurrent networks.
